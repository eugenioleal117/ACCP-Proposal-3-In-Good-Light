# In Good Light — ACCP Construction
Proposal 03 is a static architecture exhibition and brand concept for ACCP Construction, inspired by the [Oakâme style reference](https://styles.refero.design/style/a6791bc8-c49d-4e7a-a09d-877afcd04c25).

GitHub Pages serves the repository root. For local preview run `python3 -m http.server 8770` and open `http://localhost:8770/`. No build, account, or external runtime dependency is needed.

Architecture images and mockup backgrounds were generated for this proposal and are illustrative. Brand applications use the original ACCP logo. Inter is included with its SIL Open Font License. The inquiry prototype keeps all input in the current browser page and transmits nothing.
